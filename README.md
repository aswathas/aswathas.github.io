# palash.dev — no, this one's mine

A personal site for [Aswath AS](https://github.com/aswathas), built as a static
Astro site and served from Cloudflare Pages.

The whole thing looks like a macOS desktop — menubar, window chrome, dock with
magnification — and all of it is CSS and a little pointer math. No screenshot
stands in for an interface anywhere.

## What it is made of

- **Astro**, static output. No UI framework in the browser.
- **~19 KB of CSS**, one file, one set of custom properties, light and dark.
- **~9 KB of JavaScript**, hand-written, no dependencies.
- **One Cloudflare Pages Function** (`/api/live.json`) that reads the GitHub API
  at request time so star counts stay live without a rebuild.

## Things that work

| | |
|---|---|
| Dock magnification | cosine falloff around the pointer, `requestAnimationFrame` batched, disabled under `prefers-reduced-motion` |
| Window controls | close returns home, minimize stows the window and rings the running dock icon, zoom goes full screen; double-click the title bar zooms |
| ⌘K palette | searches projects, pages, writing, and files; arrow keys, enter, escape |
| Theme | auto → light → dark, persisted, applied before first paint so there is no flash |
| Search | substring AND over title, description and tags, with the result count mirrored into the URL |
| Gallery | screenshots open in a `<dialog>` with its own traffic-light chrome and arrow-key navigation |

## Running it

```bash
npm install
npm run dev          # http://localhost:4321
npm test             # node --test, no framework
npm run build        # static output in dist/
```

## Keeping it current

```bash
npm run sync         # refresh src/data/projects.json from GitHub
npm run icons        # regenerate public/projects/*.svg
```

`npm run sync` shells out to the `gh` CLI and reads your public repositories. It
is deliberately manual — no token is needed at build time, and nothing runs in
CI that you did not ask for.

## Layout

```
src/
  data/site.ts        ← edit this: identity, projects, writing, nav
  data/projects.json  ← generated by npm run sync
  layouts/Desktop.astro   menubar, window, dock
  layouts/Palette.astro   ⌘K palette
  scripts/                menubar, dock, window controls, palette trigger
  lib/                   search filter, star sync
  pages/                 home, search, 7 project pages, blog, resume, …
functions/api/live.json.ts   Cloudflare Pages Function
scripts/                sync-projects.mjs, make-icons.mjs
```

Everything you are likely to change lives in `src/data/site.ts`. It is one file
holding your identity, the seven featured projects, the writing, and the nav.

## Icons

The icon plates are original artwork generated by `scripts/make-icons.mjs`. The
marks inside them are [Lucide](https://lucide.dev) glyphs (ISC licensed).

## Deploying

`wrangler.toml` points Pages at `dist/`. Connect the repository in the Cloudflare
dashboard and every push rebuilds.

```bash
npm i -g wrangler
wrangler pages deploy dist
```
